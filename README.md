# TKD Drill Caller

Audio drill app for taekwondo: random stance-and-technique sequences, and the eight Taegeuk forms called step by step.

Static site, no build step. `index.html` is the whole app; the other files are the icon and the web app manifest so phones can install it.

Deployed with Cloudflare Pages from the `main` branch. Every push to `main` goes live.
